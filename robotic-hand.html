Project 02 — Embedded Systems & Mechatronics

ESP32-S3 Computer Vision-Controlled Robotic Hand

Completed

Designed and built an end-to-end vision-controlled mechatronic system featuring a custom ESP32-S3 hardware controller board. Real-time video feeds are processed through Google MediaPipe to extract spatial hand joint vectors, which are mapped down to low-latency servo kinematic commands driving an articulated robotic hand.

FIG 1.0 — 30-Second System Demo: Real-time hand tracking pipeline translating spatial gestures into proportional physical servo movements.

Custom Hardware Architecture & PCB Design

To eliminate timing jitter and decouple heavy servo power draw from sensitive logic rails, I designed a custom 2-layer PCB in KiCad. The board features an ESP32-S3 microcontroller communicating via I2C to a dedicated 16-channel PCA9685 PWM driver. Power delivery is managed through an AP63203 step-down buck converter stage to supply steady 3.3V power off external high-current DC inputs.

FIG 1.1 — Schematic Design: Circuit blocks for USB protection, AP63203 3.3V buck converter, and PCA9685 PWM logic.

FIG 1.2 — PCB Layout: High-current VS traces, differential native USB routing, and optimized ground pour strategy.

Protection & USB Interfaces

The USB-C interface includes proper 5.1kΩ CC pull-down resistors for USB-PD negotiation, dedicated USBLC6-2SC6 ESD protection across native USB data lines (GPIO19/20), and reverse-voltage diode isolation to safely allow simultaneous USB flashing and external DC power operation.

Manufacturing, SMT Assembly & Hardware Bring-Up

Component selection and footprints were specifically mapped to JLCPCB SMT Basic Library components to minimize manufacturing setup overhead and unit production costs. Board bring-up included benchtop power rail validation, signal integrity checks on PWM outputs using an oscilloscope, and resolving bootloader strapping-pin constraints (IO0/JP1 trace isolated for normal execution mode).
