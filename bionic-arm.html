Project 02 — Manipulation

Computer Vision-Controlled Robotic Hand

Active

This is a robotic hand I'm building, based on the open-source InMoov design, driven entirely by hand-tracking rather than pre-programmed motion. A webcam feed runs through MediaPipe, which extracts finger and joint positions in real time.

I translate those positions into servo angles and send them to an ESP32, which drives a PCA9685 PWM controller feeding five MG996R servos — one per finger. The result is a hand that mirrors my hand's pose live, rather than executing a fixed grip sequence.

Build status

I'm still sourcing and assembling hardware, but I've narrowed and finalized the fastener list — down to specific M8 and M3 hardware — for the mechanical build.
