Project 01 — Telemetry

Bare-Metal Wireless Telemetry System

Active

This is a telemetry system I built from the register level up on an STM32 microcontroller — no HAL abstractions, no vendor board-support shortcuts. I initialized and controlled every peripheral directly against the datasheet, from clock configuration to bus timing.

Sensor data comes in over I2C and SPI, then gets packaged and pushed out over a 915MHz LoRa radio link, trading bandwidth for range so the system stays useful well outside typical short-range wireless. Working at the register level made every bug a timing bug — which is where a logic analyzer became my primary debugging tool, letting me confirm bus behavior signal-by-signal against what the datasheet promised.

Why bare-metal

Building without a HAL forces a real understanding of how the peripherals actually work, not just how the library wraps them. It's slower to get running, but the payoff is a system where I can account for every byte on the bus.
