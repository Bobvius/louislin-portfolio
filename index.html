Hardware & Embedded Projects

Gesture-Controlled Bionic Arm

KiCad ESP32-S3 Buck Regulator (AP63203) Embedded C++ PWM
  • Architected an electromechanical control system pairing a Python/MediaPipe pipeline with an ESP32-S3 microcontroller to map 21 spatial hand landmarks to multi-axis movement.
  • Designed custom power & protection circuitry integrating an AP63203 buck regulator, USB-C PD with 5.1 kΩ pull-downs, onboard reverse-current protection, and dedicated ESD diodes.
  • Designed and routed a custom 2-layer PCB in KiCad with decoupled motor power supply isolation and signal integrity trace optimization across 6 servo headers.

Telemetry Node Sensor Project

STM32 (ARM Cortex-M) STM32 HAL LoRa (SPI) I2C UART/USART
  • Architected an end-to-end telemetry system using two STM32 microcontrollers to acquire, package, and transmit real-time environmental data over LoRa to a central hub.
  • Developed low-level C drivers using STM32 HAL for an Adafruit Seesaw sensor board, managing register operations, big-endian reconstruction, and fixed-point data conversions.
